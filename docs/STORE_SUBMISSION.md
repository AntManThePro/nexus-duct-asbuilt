# Shipping NEXUS to the App Store & Google Play

The web app in `www/` is the single source of truth. Capacitor wraps it in native shells; nothing in `www/` needs to change per platform.

## 0. Prerequisites
- Node 20+, `npm install`
- **Android:** Android Studio (Hedgehog+), JDK 21, SDK 35
- **iOS:** macOS with Xcode 16+, CocoaPods, an Apple Developer Program membership
- Run `npm run lint && npm test` — both CI workflows gate on them

## 1. Native projects
```bash
npm run cap:add:android
npm run cap:add:ios           # macOS only
npm run cap:assets            # icons, adaptive icons, splash from resources/
npm run cap:sync
```
`android/` and `ios/` are git-ignored on purpose; CI regenerates them. Commit them if you prefer to hand-edit native files.

Bundle / package ID: `com.antmanthepro.nexusduct` (capacitor.config.json). Change it **before** the first upload — it cannot change later.

## 2. Android — Google Play
1. **Keystore (once):**
   `keytool -genkeypair -v -keystore nexus-release.jks -alias nexus -keyalg RSA -keysize 2048 -validity 10000`
   Keep it out of git. For CI add secrets `ANDROID_KEYSTORE_BASE64` (`base64 -w0 nexus-release.jks`), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
2. **Version:** bump `versionCode`/`versionName` in `android/app/build.gradle` (or `android/variables.gradle`) for every upload.
3. **Build:** `npm run android:release` → `android/app/build/outputs/bundle/release/app-release.aab`, or let `.github/workflows/android.yml` produce it.
4. **Play Console:** create app → *App content*: privacy policy URL (host `docs/PRIVACY_POLICY.md`, e.g. via GitHub Pages), data safety = *no data collected / shared*, ads = none, target audience 18+ (trade tool), content rating questionnaire → Everyone.
5. Upload AAB to *Internal testing*, promote to Production. Store listing text is in `docs/STORE_LISTING.md`; feature graphic & 512 icon in `resources/store/`.
6. Permissions the manifest will request: `RECORD_AUDIO` is **not** added by default (Web Speech runs through the WebView's own prompt). If you add `@capacitor-community/speech-recognition`, declare it and describe it in Data safety.

## 3. iOS — App Store
1. `npm run ios` opens `ios/App/App.xcworkspace`. Set *Team*, confirm Bundle Identifier, set *Version* / *Build*.
2. **Info.plist additions** (Xcode → App → Info):
   - `NSMicrophoneUsageDescription` – "Used only for optional voice dictation of duct runs."
   - `NSSpeechRecognitionUsageDescription` – same text (required if you enable native speech recognition).
   - `NSPhotoLibraryAddUsageDescription` – "Lets you save the as-built PNG to Photos." (only if you route Save PNG to Photos)
   - `UISupportedInterfaceOrientations` – all four (the canvas benefits from landscape on iPad).
3. **Icons/splash** already generated by `npm run cap:assets` into `Assets.xcassets`.
4. *Product → Archive* → *Distribute App → App Store Connect*. Or use the `ios.yml` workflow as a pre-flight compile check and archive locally / via Xcode Cloud.
5. **App Store Connect:** new app, Bundle ID, privacy policy URL, App Privacy → *Data Not Collected*, age rating 4+, category Productivity. Upload screenshots per `docs/STORE_LISTING.md`.
6. **Review notes:** "Fully offline professional tool. No login required. Tap **BRIEFING** for a 24-second guided walkthrough; tap a Quick Slang Sample then **COMPILE TO MAP** to see the parser in action."

## 4. Web / PWA
Pushing to `main` deploys `www/` to GitHub Pages (`pages.yml`). The service worker precaches the shell so the PWA installs and runs offline; bump `CACHE` in `www/sw.js` when shipping breaking changes.

## 5. Release checklist
- [ ] `npm run lint && npm test` green
- [ ] Version bumped (package.json, Android versionCode, iOS build)
- [ ] `www/sw.js` CACHE bumped
- [ ] Privacy policy URL live
- [ ] Screenshots refreshed
- [ ] Tag `vX.Y.Z` → triggers android.yml + ios.yml artifacts
